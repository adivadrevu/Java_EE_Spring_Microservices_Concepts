# Java EE Spring Microservices Concepts

This repository contains various Java projects demonstrating different concepts and technologies. Below is a list of the projects included:

## Projects

- **Arrays_Strings**: Examples and exercises on arrays and strings.
- **BankingApp_TryWithResources**: A banking application demonstrating the use of try-with-resources.
- **Collection**: Examples and exercises on Java Collections framework.
- **DateAPI**: Demonstrations of Java's Date API.
- **DepInjectionBasics**: Basic examples of Dependency Injection.
- **Enum_Annotations**: Usage examples of Enums and Annotations.
- **ExceptionHandlng**: Examples on handling exceptions in Java.
- **Hibernate**: Examples of using Hibernate for ORM.
- **JDBC**: JDBC examples and exercises.
- **JUnit5**: Examples and exercises on using JUnit 5 for unit testing.
- **JavaDebugger**: Demonstrations of using the Java debugger.
- **Java_OOPS**: Object-Oriented Programming concepts in Java.
- **Java_OOPS2**: More advanced OOP concepts in Java.
- **Java_fundamentals**: Basic fundamentals of Java programming.
- **LambdaExpression**: Examples of using lambda expressions.
- **LambdaExpressions**: More examples of using lambda expressions.
- **Logging**: Demonstrations of logging in Java.
- **Map**: Examples and exercises on using maps.
- **Microservices**: Examples of building microservices in Java.
- **Multithreading_Concurrency**: Examples of multithreading and concurrency.
- **Servlet**: Examples of using servlets.
- **Sorting**: Examples and exercises on sorting algorithms.
- **SpringAOP**: Aspect-Oriented Programming with Spring.
- **SpringActuators**: Using Spring Actuators for monitoring.
- **SpringBatch**: Examples of batch processing with Spring Batch.
- **SpringDataJPA**: Examples of using Spring Data JPA.
- **SpringHATEOS**: Hypermedia as the Engine of Application State with Spring.
- **SpringJDBC**: JDBC examples using Spring.
- **SpringMultiDB**: Examples of using multiple databases with Spring.
- **SpringProfile**: Using Spring Profiles for environment-specific configurations.
- **SpringREST**: Building RESTful services with Spring.
- **SpringSecurity**: Securing applications with Spring Security.
- **SpringUnitTesting**: Unit testing with Spring.
- **SpringWebMVC**: Building web applications with Spring MVC.
- **Spring_Framework**: Core concepts and features of the Spring Framework.
- **Springboot**: Examples of using Spring Boot.
- **StreamsAPI**: Examples of using Java Streams API.

## Configuration
- **config.yml**: Configuration file for the projects.
